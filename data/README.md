# Data

## `corpus/` — reference aptamer corpus (not committed)

Tier 1 scores every candidate against distributions drawn from a corpus of
experimentally validated RNA aptamers. Expected CSV columns:

| column             | notes                                            |
| ------------------ | ------------------------------------------------ |
| `id`               | optional; generated if absent                    |
| `sequence`         | required; ACGU after normalisation, 20–100 nt    |
| `target_name`      | optional                                          |
| `target_pdb_id`    | nullable; required for evaluation E3              |
| `source_reference` | optional provenance string                        |

Sequences outside the configured length bounds, or containing characters
outside ACGU after `T`→`U` normalisation, are dropped and counted in the run
artifact under `corpus.dropped_reasons`.

The curated corpus is not committed to this repository. Point `corpus.path` at
a local copy, or pass `--corpus PATH`.

## `corpus/dev_placeholder_corpus.csv` — synthetic

**Not scientific data.** Generated by `scripts/make_dev_data.py` so the
pipeline can be developed before the curated corpus arrives. Runs scored
against it are stamped `publication_eligible: false` and print a warning.

## `demo_candidates.csv` — synthetic candidate batch

A mixed-quality batch (well-formed hairpins, partially degraded hairpins, and
unstructured random RNA) used for smoke-testing the ranking. Also synthetic.
